# Журнал проверки аватаров на Android-телефоне

Этот файл заполняется после каждого этапа. Не отмечать сценарий `[x]` без версии APK, устройства, результата и доказательства.

## Паспорт проверки

| Поле | Значение |
|---|---|
| Версия/commit APK | Не заполнено |
| Дата и время | Не заполнено |
| Модель телефона | Не заполнено |
| Версия Android | Не заполнено |
| Тип установки | Чистая / обновление поверх старой |
| Аккаунты | IMAP-провайдеры без адресов и паролей |
| Сеть | Wi-Fi / мобильная / без сети |
| Тема и размер шрифта | Не заполнено |
| Проверяющий | Не заполнено |

Доказательство: номер скриншота/видео, выдержка журнала без личных данных или ссылка на тестовый отчёт.

## Когда проверять этапы

| Этап | Уже можно на телефоне? | Условие начала |
|---|---|---|
| 0. Требования | Нет | Проверяется документами |
| 1. Настройки и миграция | Частично | Есть APK с экраном этапа 2 |
| 2. Экран настроек | Да | Собран debug APK |
| 3. Resolver без сети | Нет отдельно | Подключён минимум к списку на этапе 4 |
| 4. Список писем | Да | Все три пути списка подключены |
| 5. Открытое письмо | Да | Resolver подключён к заголовку |
| 6. Уведомления | Да | Разрешены Android-уведомления |
| 7. BIMI и кэш | Да | Есть безопасный сетевой resolver и тестовые домены |
| 8. Подтверждение | Да | Есть доверенный источник DMARC и тестовые письма |
| 9. Устойчивость | Да | Функция собрана целиком |
| 10. Выпуск | Да | Release candidate APK прошёл автоматику |

## Подготовка тестовых данных

Создать без использования личной переписки:

1. Контакт `Тест Контакт` с email и фотографией.
2. Контакт с email, но без фотографии.
3. Адрес, которого нет в контактах.
4. Тестовый домен с корректным BIMI.
5. Тестовый домен без BIMI.
6. Домен с неверным/слишком большим SVG.
7. Подтверждённое тестовое письмо с DMARC pass.
8. Тестовое письмо с DMARC fail или несовпадающим From.

Не записывать реальные адреса, темы и содержимое писем в этот файл.

## Финальная приёмка

- [ ] Все применимые сценарии имеют доказательство.
- [ ] Нет открытых критических и высоких дефектов.
- [ ] Чистая установка пройдена.
- [ ] Обновление старой версии пройдено.
- [ ] Откат проверен либо письменно объяснено, почему технически невозможен.
- [ ] Автоматические тесты, lint и сборка release успешны.
- [ ] Пользовательское сообщение `Обновление системы` подготовлено.
- [ ] Память проекта соответствует фактическому коду.
