# Статус реализации аватаров отправителей

Обновлено: 2026-10-14.

## Текущий результат

Реализованы общая модель существующих настроек, рабочая DI-регистрация, управляемый feature flag, отдельный экран `Основные → Аватары отправителей`, экспорт настройки уведомлений и безопасное ядро `SenderAvatarResolver`. Три старых ключа сохранены без переименования, поэтому сохранённые значения не требуют миграции.

Функция ещё не считается принятой целиком. Resolver и строгая модель подтверждения покрыты unit-тестами, но Android-адаптеры списка, письма и уведомлений ещё не передают ему контекст конкретного сообщения. Сетевой BIMI намеренно не добавлен без безопасной загрузки и доверенного источника проверки. Проверка на телефоне ещё не выполнена.

## Следующий обязательный шаг

1. Установить собранный debug APK на телефон поверх старой тестовой установки.
2. Выполнить `BASE`, `UI` и `MIGRATE` из `phone-verification.md`.
3. Проверить все 8 сочетаний старых переключателей на реальном хранилище приложения.
4. Исправить найденное и только после этого отметить этапы 1–2 `[x]`.
5. После приёмки начать этап 3: отдельный API и общий `SenderAvatarResolver`.
