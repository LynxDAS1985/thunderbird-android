# Аватары отправителей

Тематическая память функции, объединяющей фотографии контактов, логотипы компаний, буквенные заглушки и их отображение в списке писем, открытом письме и системных уведомлениях.

Статус на 2026-10-14: единые настройки, feature flag, backup и безопасное ядро resolver реализованы; подключение resolver ко всем Android-поверхностям, сеть BIMI и телефонная приёмка ещё не завершены.

## Главное решение

Использовать один общий определитель аватара `SenderAvatarResolver`. Все экраны передают ему контекст письма и настройки, а получают готовый результат с источником и признаком подтверждения. Нельзя независимо выбирать изображения внутри каждого экрана: это приведёт к разным аватарам одного письма.

## Правило статуса

В документах различаются состояния:

- `[ ]` — не начато;
- `[~]` — выполняется;
- `[x]` — выполнено и имеет доказательство проверки;
- `[!]` — заблокировано;
- `[N/A]` — неприменимо с указанной причиной.

Завершённым считается только этап, у которого заполнены автоматические проверки, ручная проверка на телефоне, найденные дефекты и ссылка на commit. План и макет не означают, что функция уже работает в APK.
