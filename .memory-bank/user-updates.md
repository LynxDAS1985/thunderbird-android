# Обновления для пользователей

Уведомление с заголовком «Обновление системы» предназначено конечному пользователю почтового приложения, а не администратору или разработчику.

Создавать запись для реально выпущенных улучшений функций или исправлений, заметных пользователю. Для документации, внутренних инструкций и организации папок уведомление не нужно.

## Шаблон будущего выпуска

- Заголовок: «Обновление системы».
- Версия: фактическая версия выпуска.
- Что улучшилось: коротко о результате для пользователя.
- Что нужно сделать: только если требуется действие пользователя.
- Состояние: черновик / включено в выпуск / доставка проверена.

Текст в этом файле сам по себе не доставляет уведомление на устройство. Перед реализацией выбрать существующий механизм информации о новой версии или согласовать новый, добавить тесты и проверить показ на телефоне. Не использовать уведомления о входящей почте для служебных сообщений без отдельной проработки.
