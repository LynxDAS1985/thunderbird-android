# История изменений

## 2026-10-09

- Добавлены русские инструкции и карта памяти для собственного Android-почтового проекта.
- Зафиксированы исходная версия, архитектура, порядок проверок, ребрендинга и выпуска.
- Добавлены журнал работ, список задач и правила пользовательских уведомлений.
- Проверки Gradle заблокированы отсутствием доступной Java; коммит и публикация не выполнены.
- Поведение и интерфейс приложения не изменены.
- Подготовлен первый невыпущенный пакет аватаров: общая модель настроек и отдельный экран с перенесёнными старыми ключами.
- JVM-тесты и форматирование первого пакета успешны; Android-сборка и APK заблокированы отсутствием Android SDK. BIMI и отображение новых логотипов не реализованы.

## 2026-10-10

- Установлены локальные JDK 21 и Android SDK вне репозитория; Android-библиотека и debug APK успешно собраны.
- Добавлен выключенный по умолчанию feature flag нового механизма аватаров и тест всех 8 сочетаний прежних настроек.
- Подготовлен единый экран старых настроек аватаров; телефонная приёмка ещё не выполнена.
- Целевым вариантом собственного приложения выбран только Thunderbird `full`; в `distrib/` оставлен один Full Debug APK.
- В план добавлены общий resolver, запрет щита без проверки конкретного письма, проверка обновления старого APK и резервное копирование настройки уведомлений.
- Commit, Push и публикация отсутствуют.

## 2026-10-15

- Единый resolver подключён к спискам писем, открытому письму, участникам и одиночным уведомлениям.
- Уведомления используют реальную фотографию контакта и точную ссылку на письмо.
- Добавлена безопасная основа BIMI с DNS/HTTPS/SVG-проверками и ограниченным кэшем; показ BIMI в интерфейсе ещё не включён.
- Профильные unit-тесты и полный `spotlessCheck` успешны; телефонная проверка ожидается.
