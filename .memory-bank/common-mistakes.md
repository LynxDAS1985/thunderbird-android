# Ловушки и ограничения

| Ситуация | Причина | Правильное действие |
|---|---|---|
| Вместо Thunderbird выбран выпуск K-9 | Оба продукта находятся в одном репозитории | Проверять префикс тега `THUNDERBIRD_` и признак prerelease |
| Неглубокий клон принят за неполные исходники | История и рабочие файлы - разные вещи | Проверять состояние файлов, sparse checkout и подмодули отдельно от глубины истории |
| Push уходит к исходному разработчику | `origin` после клонирования указывает на upstream | Сначала определить репозиторий владельца |
| Docker пересобран, телефон не обновился | Android устанавливает APK, а не серверный контейнер | Собрать, подписать и распространить Android-выпуск |
| Проверки названы успешными без запуска | Нет Java или Android SDK | Записать блокировку, настроить окружение, повторить проверки |
| Данные чужого проекта попали в память | Полное копирование шаблона с серверными настройками | Переносить только структуру и адаптированные правила |
| 🟡 Собираются сразу `fossDebug` и `fullDebug`, хотя нужен один APK | Общая задача `assembleDebug` охватывает оба product flavor и первая сборка заняла 29 минут 38 секунд | Использовать `:app-thunderbird:assembleFullDebug`, а в `distrib/` оставлять только Full APK |
| 🔴 Зелёный криптографический цвет принят за подтверждение отправителя | Часть существующих статусов относится к шифрованию и не доказывает личность автора письма | Показывать щит только по результату проверки, привязанному к конкретному письму |

Фактическая ошибка запуска 2026-10-09: Java не найдена через `JAVA_HOME`/`PATH`. Подробности в `testing.md`.
