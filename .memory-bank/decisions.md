# Решения

## D-001: Память внутри Git-репозитория, 2026-10-09

`CLAUDE.md` и `.memory-bank/` размещены рядом с `AGENTS.md`, `settings.gradle.kts` и исходниками, чтобы история правил сохранялась вместе с кодом.
Организационные образцы: соседние LibertyVPN, Avtoliberty.ru и ChatCenter. Названия продуктов, серверы, доступы и особенности их технологий не переносятся.

## D-002: Сохранить исходные технические инструкции

`AGENTS.md` остаётся регламентом Android-разработки и получает ссылку на русские правила. Память дополняет исходную документацию, а не заменяет её копией.

## D-003: Выпуск соответствует Android

Серверный деплой и Docker выполняются только после определения серверного компонента. Основной результат выпуска приложения - APK/AAB. Это предотвращает формальный «деплой», который не меняет приложение у пользователя.

## D-004: Не уведомлять пользователей о внутренних документах

Текущие изменения не меняют приложение. Правило «Обновление системы» подготовлено для будущих пользовательских изменений; доставка уведомлений в этой сессии не реализуется.

## D-005: Проверяемые инструменты вместо расширения правил без проверки

Из десяти вариантов выбраны два локальных инструмента и три рабочих шаблона; сравнение в [project-improvements.md](project-improvements.md).
PowerShell используется для вспомогательных команд Windows без новых зависимостей; Android-код остаётся на Kotlin. Инструменты ничего не устанавливают и не публикуют.
Результаты тестов инструментов, ручного разбора шаблонов и Android-проверок учитываются отдельно. Отсутствие Java не мешает проверить локальный инструмент, но не делает Gradle-проверку успешной.

## D-006: Один целевой вариант приложения — Full, 2026-10-10

Для разработки, ручной установки и будущего собственного выпуска собирать только вариант Thunderbird `full`. APK этого варианта можно устанавливать вручную; вариант `foss` не даёт проекту необходимого преимущества, но удваивает часть сборочной работы и число артефактов для проверки.

Основная команда: `.\gradlew.bat :app-thunderbird:assembleFullDebug`. В `distrib/` хранить только актуальный `thunderbird-full-debug.apk`; release в будущем собирать из варианта `full` и подписывать собственным ключом вне Git. Откат решения: вернуть сборку `foss` отдельным ADR только при появлении канала распространения, который запрещает или не поддерживает Google Play-компонент финансирования.

Решение проверено по `app-thunderbird/build.gradle.kts`: различие вариантов находится в модуле финансирования (`feature:funding:link` для `foss`, `feature:funding:googleplay` для `full`). Commit/PR отсутствует: изменения текущей сессии ещё не зафиксированы в Git.
