# Правила кода

Основной технический регламент: [AGENTS.md](../AGENTS.md). Перед изменением прочитать относящиеся к нему документы в `docs/`.

- Сохранять существующие библиотеки, стиль и архитектуру; не переносить React/Electron или серверные правила соседних проектов.
- Новые экраны писать на Compose с компонентами существующей дизайн-системы.
- Не зависеть от чужих `internal`-модулей вне разрешённых точек связывания приложения.
- Не выводить в логи адреса почты, содержимое писем, пароли и токены.
- Не добавлять аналитику, рекламу, отслеживание или разрешения в рамках организационной подготовки.
- OAuth менять в отдельной задаче с настройками собственного приложения.
- Сохранять `LICENSE`, `NOTICE` и сведения о сторонних компонентах.
- Для новой логики и исправлений добавлять тесты поведения по существующим правилам проекта; изменения только документации проверять на структуру, ссылки и соответствие фактам.
- Не откатывать чужие изменения. Не включать посторонние файлы в коммит.
