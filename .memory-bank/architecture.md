# Архитектура

Источник: [ADR-0006](../docs/engineering/adr/0006-white-label-architecture.md), [AGENTS.md](../AGENTS.md), [settings.gradle.kts](../settings.gradle.kts).

| Папка | Роль |
|---|---|
| `app-thunderbird/` | Целевое приложение, ресурсы бренда, запуск и настройки |
| `app-k9mail/` | Другое приложение на общей основе |
| `app-common/` | Связывание общих компонентов и внедрение зависимостей |
| `feature/` | Функциональные модули |
| `core/` | Общая инфраструктура |
| `library/` | Переиспользуемые библиотеки |
| `legacy/` | Старые компоненты; не место для произвольной новой логики |
| `docs/` | Исходная техническая документация и решения |
| `.memory-bank/` | Память нашей разработки, без дублирования исходной документации |

Использовать Kotlin, Jetpack Compose, Koin, Coroutines/Flow и существующий MVI. Границы `api/internal` описаны в `AGENTS.md`.
Организационная подготовка не меняет модули или зависимости. Сервер приложения и Docker-развёртывание для нашего продукта не настроены.
