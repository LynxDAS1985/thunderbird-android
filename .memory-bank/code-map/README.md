## Как устроена карта

Тематические документы объясняют назначение и содержат ссылки на код. Каталог CSV перечисляет каждый отслеживаемый Git файл, его ближайшую папку сборки и набор исходников. CSV - индекс для поиска, а не описание алгоритма каждой функции.
В новом коде встречаются пакеты `net.thunderbird`, в старом - `com.fsck.k9` и `app.k9mail`. Имя пакета само по себе не означает, что код используется только K-9.

## Перед изменением

1. Найти область в таблице выше и открыть исходный файл полностью.
2. Найти его прямые вызовы и подключение в `build.gradle.kts`/DI-модулях.
3. Проверить вариант приложения и набор исходников: `main`, `debug`, `release`, `commonMain`, `androidMain` и другие.
4. Найти ближайшие тесты и выбрать команды по [матрице проверок](../verification-matrix.md).
5. После переноса или добавления файла обновить каталог и относящийся раздел карты.

Не считать карту гарантией отсутствия ошибок или подтверждением работоспособности Android-сборки. Устаревшее описание исправлять по фактическому коду.
