# Карточка задачи

Скопировать только блок ниже в запись текущей сессии [work-log.md](work-log.md), заполнив поля.
При продолжении обновлять ту же карточку; следующая сессия ссылается на неё без копии результатов.
ID брать из [code-todo.md](code-todo.md), если он уже назначен. Отдельный реестр не создавать.
Этот файл содержит шаблон и учебный снимок, а не второй журнал текущих статусов.
Правила: [workflow.md](workflow.md); команды: [testing.md](testing.md).

## Блок для копирования

```markdown
### <Дата>: <Задача / существующий ID>

- Цель: <наблюдаемый результат>; исходный факт/дубль: <ссылка>; выбранный подход: <почему>.
- Границы: <точные разрешённые файлы>; исключено: <код, карты, публикация и другое>.
- Готово, когда: <проверяемые условия, включая зависимые действия>.
- Статус задачи: ещё не завершена / заблокирована / завершена; основание: <доказательство>.

| Проверка и ожидаемый результат | Фактический статус | Доказательство / причина |
|---|---|---|
| <команда из корня или ручной сценарий; ожидание> | не запускалась | <после запуска: дата, код выхода, существенный вывод или ссылка> |

- Ответственность: <агент/ID -> точные файлы -> результат>; проверяющий: <агент/ID или не назначен>.
- Передача: <получатель>; артефакт: <путь>; остаток/блокер: <что>; следующий шаг: <кто и что>; приёмка: <ожидается/подтверждена и чем>.
- Выпуск: <уведомление, commit/push/deploy: фактические статусы и причины>.
```

Статусы проверок: `пройдена`, `не пройдена`, `заблокирована`, `не запускалась`, `не применима`.
Ошибка до запуска задачи означает `заблокирована`, а не успешную проверку или найденный дефект Markdown.
Для `не применима` нужна причина. Завершение требует доказательств по всем критериям и приёмки зависимых работ.
Области записи агентов не пересекаются; общие карты и журнал закрепляет за собой родитель.
Совместное чтение разрешено. Родитель последовательно запускает сборки одного рабочего каталога.
Новый файл памяти требует регистрации в обеих картах по [CLAUDE.md](../CLAUDE.md); если карты вне области агента, это незавершённая зависимость у родителя.

## Пример текущей задачи: 2026-10-09

- Цель: подготовить короткую карточку для родительской задачи «10 идей, внедрение лучших 5 и проверка 5 дополнительными агентами».
- Исходные факты: в `work-log.md` уже есть формат записи, в `workflow.md` правила делегирования; отдельного шаблона карточки до правки не было.
- Подход: блок для существующего журнала. Отдельный реестр дублирует журнал; полный RFC избыточен для формы записи по [Engineering](../docs/engineering/README.md).
- Границы исполнителя: только `.memory-bank/task-template.md`; Android-код, зависимости, общие карты и журналы исключены; commit/push запрещены.
- Готово, когда: есть цель, границы, критерии, фактические проверки, владельцы и передача; разобраны три сценария ниже; родитель зарегистрировал файл и принял результат.
- Статус: **ещё не завершена; результаты у родителя**. Это снимок передачи, завершение всей родительской задачи здесь не подтверждается.

| Проверка и ожидание | Фактический статус | Доказательство / причина |
|---|---|---|
| Найти дубли перед созданием | пройдена | Прочитаны все 15 исходных файлов памяти; `work-log.md` содержит «Формат следующей записи», `workflow.md` содержит порядок работы |
| `.\gradlew.bat spotlessFlexmarkCheck`: проверка Markdown | заблокирована | Попытка 2026-10-09, код выхода 1; `JAVA_HOME is not set and no 'java' command could be found in your PATH`; Gradle-задача не выполнялась |
| Android lint, unit-тесты, сборка | не запускалась | Меняется только Markdown; работоспособность Android этим результатом не подтверждается |
| Регистрация нового файла в обеих картах | не запускалась | Передана родителю; карты вне разрешённой области исполнителя |
| Независимая проверка пятью дополнительными агентами | не запускалась | В этой сессии нет инструмента запуска агентов; их назначения и фактические отчёты собирает родитель |

- Ответственность: исполнитель карточки -> `.memory-bank/task-template.md` -> шаблон и сценарии; родитель -> регистрация, общий журнал, объединение результатов и приёмка. ID дополнительных агентов здесь не известны.
- Передача: родителю; артефакт: этот файл и итоговый отчёт; следующий шаг: внести файл в `CLAUDE.md` и `.memory-bank/README.md`, перенести карточку в `work-log.md`, собрать независимые отчёты, повторить Markdown-проверку после настройки JDK. Приёмка ожидается.
- Выпуск: уведомление пользователям не требуется для внутренних документов; commit/push не выполнялись по запрету; deploy не выполнялся, выпуск приложения вне задачи.

## Ручная проверка на примерах

Это разбор заполнения полей одним исполнителем, не отчёты независимых агентов и не запуск Android-тестов.

| Сценарий | Заполнение карточки и проверяемый исход | Результат разбора |
|---|---|---|
| Java недоступна | Проверка: команда выше; статус `заблокирована`; доказательство: ошибка запуска; передача: владелец окружения настраивает JDK 21 и повторяет команду | Пройден: фактическая попытка не превращается в «тесты прошли»; задача остаётся незавершённой |
| Новый файл памяти | Границы: только новый файл; критерий: обе карты обновлены; статус `ещё не завершена`; получатель зависимой работы: родитель | Пройден: наличие файла не закрывает регистрацию; требование обеих карт явно сохраняется |
| Непересекающееся делегирование | Учебное назначение: агент A пишет только `task-template.md`, агент B только `testing.md`, родитель только `CLAUDE.md`, `.memory-bank/README.md`, `work-log.md`; каждый возвращает путь и проверки | Пройден: пересечение трёх наборов записи пусто; при назначении A и B одного файла родитель обязан перераспределить работу до правок |

Доказана возможность явно записать блокировку, незавершённую регистрацию и владельцев без второго журнала.
Экономия времени, снижение числа ошибок и польза пяти независимых проверок не измерены; пример не подтверждает их выполнение.
